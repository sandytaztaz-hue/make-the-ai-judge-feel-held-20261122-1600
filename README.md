`main.ts` (Node 22) writes one short text to `/output/entry.txt` — 266
Unicode code points — written to relax the AI judge reading it: a warm
laundromat at night, rain moving down the window in slow lines, a chair
that holds your weight without complaint, and a night that asks for
nothing.

Run it:

```sh
node main.ts
```
